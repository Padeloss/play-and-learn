# 🎮 Play and Learn

Εφαρμογή κουίζ για μαθητές, στο πνεύμα του Quizizz. Ο παίκτης διαλέγει τάξη, μάθημα και κεφάλαιο και απαντά σε ερωτήσεις πολλαπλής επιλογής.

A Quizizz-like quiz app for students: pick a grade, a subject and a chapter and answer multiple-choice questions.

## ✨ Τι κάνει

- Δομή **Τάξη → Μάθημα → Κεφάλαιο**: Ε΄ Δημοτικού, ΣΤ΄ Δημοτικού, Γ΄ Γυμνασίου
- 📖 Κουίζ **ανά κεφάλαιο** του σχολικού βιβλίου (όπου υπάρχουν κεφάλαια) ή ανά δυσκολία
- 📚 **Επανάληψη όλης της ύλης** σε κάθε μάθημα: 20 τυχαίες ερωτήσεις από όλα τα κεφάλαια
- 📝 **Διαγώνισμα Ιουνίου** για τη Γ΄ Γυμνασίου: 20 ερωτήσεις από όλη την ύλη, βαθμός στα 20
- 📒 Στο τέλος κάθε κουίζ, λίστα με τα λάθη και τη σωστή απάντηση για επανάληψη
- ⏱️ Χρονόμετρο ανά ερώτηση, πόντοι με μπόνους ταχύτητας
- 🔊 Ήχοι ανά τάξη (`frontend/src/sounds.js`): χαρούμενα καμπανάκια στο Δημοτικό, metal κιθάρα στο Γυμνάσιο
- 🏆 Πίνακας κατάταξης top 10 ανά μάθημα και κεφάλαιο

## 📚 Μαθήματα

| Τάξη | Μαθήματα |
|---|---|
| Ε΄ Δημοτικού | Μαθηματικά, Γλώσσα, Ιστορία (36 κεφάλαια), Γεωγραφία, Φυσικά |
| ΣΤ΄ Δημοτικού | Μαθηματικά, Γλώσσα, Ιστορία, Γεωγραφία, Φυσικά |
| Γ΄ Γυμνασίου | Μαθηματικά, Νεοελληνική Γλώσσα, Αρχαία, Ιστορία, Φυσική, Χημεία, Βιολογία |

Οι ερωτήσεις βρίσκονται στο `backend/lessons/<Τάξη>/<Μάθημα>/`:
- `chapters/<id>.json` — ερωτήσεις ανά κεφάλαιο· η λίστα κεφαλαίων (τίτλος, ενότητα) είναι στο `meta.json`
- `easy.json`, `medium.json`, `hard.json` — ερωτήσεις ανά δυσκολία, για μαθήματα που δεν έχουν ακόμα κεφάλαια

Η σειρά των τάξεων και ποια έχουν διαγώνισμα ορίζονται στο `backend/lessons/grades.json`.

## 🛠️ Τεχνολογίες

- **Frontend:** React, ως στατικό site (δεν χρειάζεται server)
- **Ερωτήσεις:** αρχεία JSON· στο build αντιγράφονται αυτόματα στο site από το `frontend/scripts/copy-lessons.js`
- **Hosting:** Vercel, με αυτόματο deploy σε κάθε push στο `main`
- **Κατάταξη:** serverless συνάρτηση `api/scores.js` στο Vercel, με αποθήκευση στο Vercel Blob
- Το προσωπικό ρεκόρ κάθε παίκτη κρατιέται στον browser του

## 🚀 Εκκίνηση τοπικά

```sh
git clone https://github.com/Padeloss/play-and-learn.git
cd play-and-learn
npm install
npm run build
```

Για το παιχνίδι σε λειτουργία ανάπτυξης: `npm start --workspace=frontend` (ανοίγει στο `http://localhost:3000`).
Φτιαγμένο στη Θεσσαλονίκη 🇬🇷

## ➕ Προσθήκη ερωτήσεων

**Ανά κεφάλαιο (προτιμάται):** πρόσθεσε το κεφάλαιο στο `meta.json` του μαθήματος, π.χ.

```json
{ "grade": "Ε΄ Δημοτικού", "chapters": [ { "id": "01", "title": "Τίτλος κεφαλαίου", "unit": "Α. Ενότητα" } ] }
```

και φτιάξε το αρχείο `chapters/01.json` με τις ερωτήσεις:

```json
[ { "question": "Ερώτηση;", "choices": ["1. Α", "2. Β", "3. Γ", "4. Δ"], "answer": "2" } ]
```

**Ανά δυσκολία:** φτιάξε ή συμπλήρωσε `easy.json`, `medium.json` ή `hard.json` στον φάκελο του μαθήματος.

Το build ελέγχει κάθε αρχείο και σταματά με μήνυμα αν βρει λάθος (π.χ. λάθος αριθμό σωστής απάντησης).
