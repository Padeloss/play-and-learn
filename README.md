# 🎮 Play and Learn

Εφαρμογή κουίζ για μαθητές, στο πνεύμα του Quizizz. Ο παίκτης διαλέγει μάθημα και δυσκολία και απαντά σε ερωτήσεις πολλαπλής επιλογής.

A Quizizz-like quiz app for students: pick a subject and a difficulty level and answer multiple-choice questions.

## ✨ Τι κάνει

- Κουίζ ανά **τάξη**: Ε΄ Δημοτικού, ΣΤ΄ Δημοτικού, Γ΄ Γυμνασίου και γενικές ερωτήσεις Γυμνασίου–Λυκείου
- Κάθε μάθημα δείχνει σε ποια τάξη απευθύνεται, με 3 δυσκολίες (εύκολο · μέτριο · δύσκολο)
- 📝 **Διαγώνισμα Ιουνίου** για τη Γ΄ Γυμνασίου: 20 ερωτήσεις από όλη την ύλη, βαθμός στα 20
- 📒 Στο τέλος κάθε κουίζ, λίστα με τα λάθη και τη σωστή απάντηση για επανάληψη
- ⏱️ Χρονόμετρο ανά ερώτηση, πόντοι με μπόνους ταχύτητας, 🔊 ήχοι
- 🏆 Πίνακας κατάταξης top 10 ανά μάθημα και δυσκολία

## 📚 Μαθήματα

| Τάξη | Μαθήματα |
|---|---|
| Ε΄ Δημοτικού | Μαθηματικά, Γλώσσα, Ιστορία, Γεωγραφία, Φυσικά |
| ΣΤ΄ Δημοτικού | Μαθηματικά, Γλώσσα, Ιστορία, Γεωγραφία, Φυσικά |
| Γ΄ Γυμνασίου | Μαθηματικά, Νεοελληνική Γλώσσα, Αρχαία, Ιστορία, Φυσική, Χημεία, Βιολογία |
| Γενικά (Γυμνάσιο–Λύκειο) | Άλγεβρα, Γεωμετρία, Φυσική, Βιολογία, Γεωγραφία, Ιστορία, Νεοελληνικά, Αρχαία, Python |

Οι ερωτήσεις βρίσκονται στο `backend/lessons/<Τάξη>/<Μάθημα>/<δυσκολία>.json`.
Η σειρά των τάξεων και ποια έχουν διαγώνισμα ορίζονται στο `backend/lessons/grades.json`,
και η τάξη κάθε μαθήματος στο `meta.json` του φακέλου του.

## 🛠️ Τεχνολογίες

- **Frontend:** React, ως στατικό site (δεν χρειάζεται server)
- **Ερωτήσεις:** αρχεία JSON· στο build αντιγράφονται αυτόματα στο site από το `frontend/scripts/copy-lessons.js`
- **Hosting:** Vercel, με αυτόματο deploy σε κάθε push στο `main`
- **Κατάταξη:** serverless συνάρτηση `api/scores.js` στο Vercel, με αποθήκευση στο Vercel Blob
- Το προσωπικό ρεκόρ κάθε παίκτη κρατιέται στον browser του

## 🚀 Εκκίνηση τοπικά

```sh
git clone https://github.com/Padeloss/play-and-learn.git
cd play-and-learn
npm install
npm run build
```

Για το παιχνίδι σε λειτουργία ανάπτυξης: `npm start --workspace=frontend` (ανοίγει στο `http://localhost:3000`).
Φτιαγμένο στη Θεσσαλονίκη 🇬🇷

## ➕ Προσθήκη ερωτήσεων

Φτιάξε ή συμπλήρωσε ένα αρχείο `easy.json`, `medium.json` ή `hard.json` στον φάκελο του μαθήματος, π.χ. `backend/lessons/Ε΄ Δημοτικού/Μαθηματικά/`.
